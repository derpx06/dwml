DWM LAB - CODE PACK (2615PE11, T.Y. B.Tech CE)
==============================================
Install once:
    pip install pandas numpy matplotlib scikit-learn mlxtend scipy jupyter

Run any program from THIS folder (so the data/ and out/ folders are found):
    python a1_preprocessing.py           Assignment 1 - preprocessing (Titanic)
    python a2_olap_datamart.py           Assignment 2 - ETL, sales data mart, data cube, OLAP
    python a3_apriori.py                 Assignment 3 - bookstore Apriori (40% / 60%)
    python a4_loan_classification.py     Assignment 4 - loan approval: DT, NB, KNN, SVM
    python a5_clustering_miniproject.py  Assignment 5 - mini project: customer clustering

Or open the .ipynb files in Jupyter Notebook and run the cells top to bottom.

data/   input files (titanic.csv is the real open dataset; the rest are created by the programs)
        sales_mart.db is the SQLite data mart - open it with "DB Browser for SQLite"
out/    charts (.png) and cleaned/segmented CSVs produced by the programs
out_a*.txt  the exact console output of each program
